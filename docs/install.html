SPLITSGATE / QUICK START

READY.
SET. RUN.

No installer and no manual file placement. Download the launcher, start your game, and Splitsgate handles the overlay.

DOWNLOAD SPLITSGATE ↓

Download

Get Splitsgate.zip from the latest release, then extract the folder anywhere convenient.

Start the game

Open Splitgate 1 or Splitgate 2 and wait until the game window appears.

Run Splitsgate

Open Splitsgate.exe. The launcher detects which supported game is running and loads the HUD.

Open settings

Double-tap R in game, or press `. Move, resize, recolor, and choose which optional features are enabled.

Race

Enter a race. Splitsgate detects the map, timer, difficulty, balls, splits, and personal best automatically.

Optional extras

Enable community submissions after connecting your account. Keep Medal open and switch on Medal PB Clips to save new best runs.
